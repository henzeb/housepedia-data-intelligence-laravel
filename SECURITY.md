# Security policy

## Supported versions

Security fixes are released for the latest minor release of the current major version.

| Version | Supported |
|---------|-----------|
| 1.0.x   | Yes       |

## Reporting a vulnerability

Report a vulnerability by email to henzeberkheij@gmail.com instead of in a public issue.
Include:

- the affected version of `henzeb/housepedia-data-intelligence-laravel`;
- the steps to reproduce it;
- its impact.
